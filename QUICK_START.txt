💡 TIPS
═══════════════════════════════════════════════════════════════════════════════

Exploring Code:
  • Start with src/App.tsx - see the routing structure
  • Then explore pages/ - see full page components
  • Then explore components/ - see reusable components
  • Check types.ts - understand the data model

Understanding Mock Data:
  • Open src/services/mockData.ts
  • See sample portfolios and items
  • Understand calculation functions

Enabling Real API:
  • In src/services/api.ts, set USE_MOCK_DATA = false
  • Build your Flask backend
  • Update API_BASE_URL as needed
  • Restart dev server

Building Backend:
  • Use FLASK_BACKEND_TEMPLATE.md as starter code
  • Implement required endpoints from INTEGRATION_GUIDE.md
  • Test with Postman or curl
  • Enable CORS before integrating
